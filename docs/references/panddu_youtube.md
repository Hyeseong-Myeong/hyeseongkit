영상에서 소개하는 AI 워크플로우는 **'나에게 필요한 기능만 직접 설계'**하는 것을 핵심 가치로 삼고 있으며, 총 4개의 계층으로 구성되어 있습니다. 각 계층의 스택과 역할은 다음과 같습니다.

1. 영속 계층 (Persistence Layer)
도구: Bear (노트 앱)
역할: 모든 데이터의 기록 및 저장소입니다. Bear는 마크다운을 완벽 지원하며, 강력한 **CLI(Command Line Interface)**와 최근 지원하는 **MCP(Model Context Protocol)**를 통해 AI가 직접 읽고, 쓰고, 수정하고, 검색할 수 있도록 설계되었습니다. (01:22 - 01:52)
2. 스킬 계층 (Skill Layer): mingus-kit
역할: AI가 실제 업무를 수행하기 위한 '능력'들을 모아둔 프로젝트입니다. Claude Code, Codestral, Antigravity 등 다양한 LLM을 지원하도록 벤더 의존성을 최소화했습니다. (02:10 - 03:20)
핵심 기능:
세션 영속화: 업무 히스토리를 Bear에 저장하여 기기를 바꿔도 연속성을 유지합니다.
API 통합: 구글 시트, 유튜브, 구글 애널리틱스, 캘린더 등과 연동하여 데이터 분석 및 자동 리포팅을 수행합니다.
3. 응용 계층 (Application Layer): mingus-studio
역할: 영상 제작 및 콘텐츠 생산을 위한 실질적인 자동화 도구입니다. (03:25 - 04:40)
스택 및 도구:
음성 합성: GPT-SoVITS를 활용한 개인 목소리 학습(현재는 보완 중).
자막 자동화: Whisper 모델을 기반으로 받아쓰기를 수행하며, 시작 단계부터 타겟 XML 템플릿을 생성하여 타이밍 오류를 방지합니다.
4. AI 연동 계층 (Integration Layer): mingus-agent
역할: 프로그램 내부에서 LLM을 연동하여 지능적인 제어를 수행합니다. (04:44 - 06:27)
스택: Kotlin 기반의 Koogle 프레임워크.
특징:
JVM 환경에 최적화되어 있으며, 코틀린 DSL을 통해 흐름과 상태를 명확히 관리합니다.
단순 API 호출이 아니라, 인풋과 아웃풋을 구조화된 객체로 처리하여 복잡한 JSON 파싱 노가다를 줄이고 코드 가독성을 극대화합니다.
질문 태그 분류 등 상황에 따라 경량 로컬 LLM부터 고성능 모델까지 유연하게 모델을 스위칭합니다.
요약: 워크플로우 핵심 철학
모든 시스템은 **'현업에서 내가 직접 사용하는 툴(JVM/Kotlin)'**과 **'내가 제어 가능한 데이터 베이스(Bear/Markdown)'**를 중심으로 구축되어, 남의 자동화 틀에 나를 맞추지 않고 필요한 기능만 효율적으로 개발하는 것이 핵심입니다.
